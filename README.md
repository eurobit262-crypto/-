# Система учёта спецодежды и инвентаря РЖД
Web-приложение для автоматизации выдачи, возврата и списания спецодежды и инвентаря на железнодорожной станции.

О проекте
Приложение предназначено для кладовщиков железнодорожных станций. 
Оно позволяет:

1.Вести учёт сотрудников, должностей и станций

2.Управлять складскими остатками инвентаря

3.Оформлять выдачу и возврат инвентаря

4.Контролировать должников с визуальной подсветкой просрочек

5.Настраивать нормы выдачи по должностям

6.Формировать отчёты и выгружать их в Excel

Технологический стек:
